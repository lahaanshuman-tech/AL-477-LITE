# Contributing to AL-477 Lite

Thank you for your interest in contributing!  
AL‑477 Lite is an educational project. Contributions should focus on clarity, portability, and documentation.

---

## How to Contribute
1. **Fork the Repository**: Create your own copy.
2. **Create a Branch**: Use descriptive names (e.g., `java-port`, `docs-update`).
3. **Make Changes**: Ensure code is well‑documented and tested.
4. **Submit a Pull Request**: Clearly describe your changes.

---

## Contribution Guidelines
- Keep code simple and educational.
- Add comments explaining algorithmic steps.
- Update `README.md` and `SPEC.md` if behavior changes.
- Do not add cryptographic claims — this is **not** a secure cipher.

---

## Ports
If you are porting AL‑477 Lite to another language:
- Follow the algorithm flow in `SPEC.md`.
- Maintain parity with Python reference implementation.
- Document differences in a `PORTING.md` file.

---

## Code of Conduct
- Be respectful and constructive.
- Focus on learning and collaboration.
- No plagiarism or redistribution of proprietary STD/PRO versions.
